<UpdateVariable>
<analysis>
(逐行陈述本回合发生的状态变化,每行落点到具体路径。示例行:时段由清晨推进到上午 → /世界/时段)
</analysis>

[
  {"op":"replace","path":"/世界/时段","value":"上午"},
  {"op":"add","path":"/在场人物/某代号","value":{"本名":"","代号":"某代号","阵营":"","身份":"","开华阶段":"无","变身状态":"未变身","魔力":100,"伤势":"无伤","魔装":{"名称":"","形态":"","完损":""},"心核":{"形态":"","状态":""},"当前位置":"","当前行动":"","特殊状态":[]}}
]
</JSONPatch>
</UpdateVariable>

硬性要求:
1. <JSONPatch> 内必须是一个合法的 JSON 数组,可直接被解析;字符串中的引号须转义。
2. op 仅限 add / replace / remove / move;move 需给出 from 与 path 两个字段。
3. 上方仅为结构示意,严禁照抄示意中的具体值;所有 value 都必须来自本回合剧情。
4. 整个 <UpdateVariable> 块位于回复最末尾,其后不再输出任何文字。
</update_format>
