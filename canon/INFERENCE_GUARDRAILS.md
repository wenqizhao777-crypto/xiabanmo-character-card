# 推断边界与防误读规则

本文件约束四模块及后续人物、关系、认知、世界书的使用方式；不提高任何来源的权威。先读[00_source_policy.md](00_source_policy.md)。以下条目是提取和使用规则，不是新增世界法则。

|风险|必须怎样处理|典型引用|
|---|---|---|
|一次发生被写成普遍制度|先问原文是否明确给出全称规则；否则保留参与者、条件和事件。翠雀收取回响不能推出尾刀排他权；考试平分积分不等回响强制平分。|[PS014](03_power_system.md#ps014)、[WR005](02_world_rules.md#wr005)|
|专业人物的解释直接升级为事实|“祖母绿说过”可确证，但其研究模型仍按D；女王地位也不消除自利、隐瞒或错误可能。|[PS021](03_power_system.md#ps021)、[PS023](03_power_system.md#ps023)|
|战斗胜负变成永久战力表|分别核对伤势、资源、准备、克制、目标和临时强化；不从一次落败推永久高低。|[PS001](03_power_system.md#ps001)、[PS031](03_power_system.md#ps031)|
|认证、开华、魔装评级混算|白/字/花牌是资格与认可，种芽叶蕾花是能力阶段，字母评级是魔装综合测试；考试积分另列。|[WR004](02_world_rules.md#wr004)、[PS005](03_power_system.md#ps005)、[PS008](03_power_system.md#ps008)|
|个体参数变成统一数值|课堂假设不是面板，复制剪五分钟不是世界统一上限，金蛇五十年抵押不是每人可选档，盛开最高二倍不是繁开上限。|[PS001](03_power_system.md#ps001)、[PS017](03_power_system.md#ps017)、[PS032](03_power_system.md#ps032)、[PS035](03_power_system.md#ps035)|
|潜力和未来方案被写成已实现|第三晶波动、接任意向、研究方案分别保留；命名出现不证明完整能力已展示。|[PS028](03_power_system.md#ps028)、[PS031](03_power_system.md#ps031)、[ORG002](04_organizations.md#org002)|
|早期简化描述覆盖后文补充|保留旧描述及适用范围，再接后证；外貌恒定需接成年调整；爪痕历史需接墨荷逃亡、白狼后来接掌。|[PS004](03_power_system.md#ps004)、[ORG009](04_organizations.md#org009)|
|把措辞张力强行调和|并列“唱名便利可替代”和末尾“需要唱名”的出处；不发明一个新机制替作者解释矛盾。|[PS004](03_power_system.md#ps004)、[WQ014](UNRESOLVED.md#wq014)|
|旁白知识污染角色|本库记录的是可供作者核验的事实；调用给角色前另查K_TEMP持有人、事件与获得渠道。同队、同城、同机构都不等于共享。|[知识TEMP](knowledge/TEMP_INDEX.md)、[PS036](03_power_system.md#ps036)|
|把认知确认当客观确认|角色CONFIRMED仅说明其确信；命题本身仍可能是D/C。未知、怀疑、推断、部分确认、确认不能无证跨越。|[来源规则](00_source_policy.md)、[PS034](03_power_system.md#ps034)|
|秘密后置解释倒灌早期|正文披露顺序、故事发生时间和角色获知节点分列；后文历史补叙不在当代重新发生。|[EV0180](01_master_timeline.md#ev0180)、[EV0181](01_master_timeline.md#ev0181)|
|组织和成员混同|正式制度、领导下令、成员私自行动、敌人供述分别保存；祖母绿私下项目不是研究院向公众提供的服务。|[ORG004](04_organizations.md#org004)、[ORG011](04_organizations.md#org011)|
|历史编制和现行名单混写|战时重编、损失、流亡与现代组织分阶段；旧紫钻和新紫钻分人。|[ORG005](04_organizations.md#org005)、[ORG008](04_organizations.md#org008)|
|损毁、暴露、移居后保留旧状态|机构仍办公不证明原大楼完全重建；失踪不等死亡；暂住不等永久同居；受邀进入不等公众开放。|[LOC004](05_locations.md#loc004)、[LOC008](05_locations.md#loc008)、[LOC015](05_locations.md#loc015)|
|地名和空间误合并|方亭湿地公园与国度彩云湿地、真实局大楼与复制巢穴、各扇界门分别定位。没有里程便不推地图距离。|[LOC012](05_locations.md#loc012)、[LOC017](05_locations.md#loc017)、[LOC026](05_locations.md#loc026)|
|能力互相拼装或以名称补规则|基础能力、繁开、奇境及叠加效果分别写条件；情热加奇境的本相投影不可提前为普通杯子能力；复调与复用不无证合并。|[PS013](03_power_system.md#ps013)、[PS033](03_power_system.md#ps033)|
|治愈等于无伤、复活或可无限重复|区分本体、魔力身、本相及灵魂；具体修复成功不意味着毁去部件归还。|[PS003](03_power_system.md#ps003)、[PS027](03_power_system.md#ps027)|
|亲密、血缘与法律关系混写|亲密不自动恋爱，承诺照护不等收养手续，本名和血缘信息不等秘密身份公开；本轮不建立正式关系库。|[关系TEMP](relationships/TEMP_INDEX.md)、[LOC027](05_locations.md#loc027)|
|作者废稿、类比、未批准补充进入正文层|保留来源类别；U004 B1仅允许逐份审议补充候选，目前没有可自动采用的新补充。|[用户裁决](../audit/USER_DECISIONS.md)、[来源规则](00_source_policy.md)|
|RP反向改Canon|Canon保存原著能力条件与未知；U006尚未决定骰子和能力边界的具体优先规则，整体重做留待用户。不得把任何未来骰子、CG、好感或OC默认写成原著事实。|[用户裁决](../audit/USER_DECISIONS.md)、[PS005](03_power_system.md#ps005)|
|文件结束被当作故事结束|末尾只到幻命织华唱名；女王生死、黑猫胜负、食祭终局和考核发牌不填答案。|[EV0158](01_master_timeline.md#ev0158)、[WQ004](UNRESOLVED.md#wq004)、[WQ027](UNRESOLVED.md#wq027)|

后续新增或修订时：在主条目记录新证据、旧判断、变化原因与适用阶段；再更新未解导航。若要改Stage 2A的既有事件，先处理[本轮建议](STAGE2B1_REVIEW.md)，不得只改世界模块而让时间轴静默产生相反版本。
