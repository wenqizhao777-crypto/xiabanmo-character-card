## 使用方法

先选人物，再选事件阶段；不得直接将“末尾状态”用于开篇。章节回忆的揭晓位置与发生年代不同。关系与认知仅为TEMP导航，尚未进入Stage 2B-3／2B-4。资料并列秘密别名不等人物知道别名。

- Tier A：核心、多阶段复杂人物，独立完整档案及八维快照。
- Tier B：持续影响主线的重要配角，独立标准档案。
- Tier C：事件、能力、身份或传播链需要的功能性简档。
- Tier D：仅为区分未具名主体的最小索引。

共70条稳定主体记录：A 10、B 26、C 32、D 2；A/B独立完整或标准档案36份，C/D简档34份。CH044与CH069同一性未定，因此本数是记录数，不宣称已证同样数量的独立自然人。
