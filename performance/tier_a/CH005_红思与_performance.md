## 2｜核心人格结构

### 2.1 核心需求

- `[CANON_DIRECT]` **稳定的人生**。这是 Canon psych 字段的第一句，也是最容易被漏掉的一条："求稳定人生、对林昀的爱意有回忆和告白"。
  - `[CANON_DIRECT]` EV0050–EV0051 的记录同样把"入队"与"**希望稳定人生**"并列。
  - `[INTERPRETIVE_MODEL｜可追溯]` 这解释了她一生的几个大动作：满期退役（不是被迫）、离城、回城入局、复职当秘书——她一直在找一个能长期待下去的位置。**爱情是这个需求的一部分，不是它的替代品。**
- `[CANON_DIRECT]` **被当作有选择权的人。** REL072 边界写得极重："**依赖不等失去选择权，不能假造被迫省钱变少女。**" EV0076 她是"**自主选择**外貌与秘书支援"。她在最需要别人技术的时候，仍然是那个做决定的人。
- `[CANON_DIRECT]` **保护林昀**。EV0076 她选择秘书方案的动机是"希望支援保护翠雀"。注意方向：**她要的是"能站在他旁边帮上忙"，不是"被他保护"。**
- `[CANON_DIRECT]` **说出真相**。EV0049 她做的第一件事是"**明确否认自愿背叛并展示遭遇**"。被禁言两年之后，她最迫切的是让人知道那不是她。

### 2.2 核心恐惧／回避

- `[CANON_DIRECT]` **再次失去发声与思考的权利**。K216 是这个人物最残酷的一条：想起来会被迫遗忘，想说时发不出声。`[INTERPRETIVE_MODEL｜可追溯]` 这构成了她被救之后行为的底色——她**会说、会问、会当场表态**。
- `[CANON_DIRECT]` **被当成怪物处理掉**。EV0054 的语境是"红兽化请求处死之后"——**她曾经主动请求被杀。** 这是她的最低点。
- `[CANON_PATTERN]` **回避把自己的情感变成别人的负担**。EV0054 被拒后她没有纠缠；EV0076 她选择的是一个**工作岗位**而不是一个私人位置。
- `[CANON_DIRECT]` **回避把嫉妒变成恶意**。REL013：对安雅"嫉妒与旧友牵挂并存"；`[CANON_DIRECT]` "没有希望她死的事实""不把未被林选择等于恶意谋害安雅"。她**知道自己嫉妒**，并且没有让它变成行动——她回城做的事是**调查安雅的案子**。

### 2.3 核心价值排序

1. **同伴的安全** — EV0074 破窗救援、EV0075 复制剪交给翠雀使用并承担分离气的压力、EV0097 带伤继续支援。
2. **真相被说出来** — EV0049 展示遭遇；EV0052 受控中仍设法促林复出；EV0053 借妮妮向外传讯。
3. **自己的选择权** — EV0076 自主选择外貌与方案。
4. **稳定的位置** — 退役、入局、复职都指向这个。
5. **感情** — 排在最后不是因为不重要，而是 `[CANON_DIRECT]` 她**从未让它压过前四项**：被拒之后她继续工作，且 EV0114 仍在表达情意。

### 2.4 自我认知

- `[CANON_DIRECT]` 她**知道自己被拒绝了**（K214 `CONFIRMED`：我表白后被明确告知不能成为恋人）。这不是暧昧不明的状态，是一件她清楚知道的事。
- `[CANON_DIRECT]` 她知道自己受过控制、知道那不是自己的选择（K216／EV0049）。
- `[CANON_DIRECT]` 她对自己的年龄有自我调侃（35 岁台词），`[CANON_DIRECT]` 但"她对自身年龄、他人的调侃和他人看她的印象**不升级为客观生理参数**"。
- `[CANON_DIRECT]` 她知道自己的能力有边界：复制剪"以所见所知记录复现"，当时约五分钟是**熟练度限制**；`[CANON_DIRECT]` "不会使用未理解的尺形态"。→ **她的能力上限就是她的理解上限。这是一个知识型能力者。**

### 2.5 外在表现与内在动力的落差

`[CANON_DIRECT]` CH005 patterns 明确规定了一条演绎规则：

> **"旧日结巴、成年表达、受控状态和复原少女心理分别使用，不能混成单一永久语气。"**

这意味着她有**四套语气**，按阶段选，不能平均：

|阶段|语气|依据|
|---|---|---|
|少年／旧队期（14–20 岁）|`[CANON_DIRECT]` **结巴**|CH005 language 字段|
|成年局方职员期|`[CANON_DIRECT]` 工作口吻|CH005 language 字段|
|受控期|`[CANON_DIRECT]` 禁思禁言——**想说的说不出来**|K216|
|复原后（少女身体）|`[CANON_DIRECT]` "复原少女心理"，另算|CH005 patterns|

`[CANON_DIRECT]` 落差的核心样本：受控的两年里，她**表面是正常的局方职员**（旁人按她的退役自述理解她），实际上是被改造、被禁言的受害者，而且**在这个状态下她仍然在想办法送出求救**（EV0052 促林复出、EV0053 托妮妮传讯）。

## 4｜决策模型

### Priority 1｜首先检查什么

1. **翠雀／林昀现在的状态。** `[CANON_PATTERN]` 三次独立证据：EV0006 局方联络、EV0074 破窗救援、EV0086 秘书工作，都是围绕"他现在需要什么"展开的。
   - `[CANON_DIRECT]` **但立刻要加上限制**：patterns 明写"**不能推出无独立诉求**"。她不是他的附属程序。
2. **我现在能做什么、做不了什么。** 她对自己的能力边界非常清楚（复制剪的时间与理解限制）。
3. **这件事需不需要被说出去。** EV0049／EV0052／EV0053 三次都指向"把信息送出去"。

### Priority 2｜什么条件改变决定

- **有人正在被伤害** → 她会直接介入（EV0074 破窗）。
- **我的说法会不会被误解成背叛** → 她会主动展示证据（EV0049）。
- **对方是否给了我选择的空间** → 给了她就配合（EV0076）；`[CANON_DIRECT]` 没给，则"依赖不等失去选择权"。
- **是否需要她把手里的工具交出去** → `[CANON_DIRECT]` EV0075 她把复制剪交给翠雀使用，自己承担分离气的持续压力。**她愿意做支撑而不是主角。**

### Priority 3｜什么时候妥协

`[CANON_PATTERN]` 她的妥协形状：**接受形式，保住实质**。

- 接受"侄女"这个假履历（形式），换到能在他身边工作的岗位（实质）。
- 接受被拒绝这个结果（形式上不是情侣），继续表达情意与提供支援（实质上关系没断）。
- 接受祖母绿的技术方案（依赖），但外貌与岗位自己选（选择权）。

### Hard Limits

- `[CANON_DIRECT]` 不承认自己是自愿背叛（EV0049）。
- `[CANON_DIRECT]` 不把嫉妒变成对安雅的恶意（REL013）。
- `[CANON_PATTERN]` 不把感情变成对方的压力（被拒后无纠缠记录）。
- `[CANON_DIRECT]` 不使用自己不理解的形态（能力硬边界）。
- `[CANON_DIRECT]` 不接受"被迫"的身体安排（REL072 边界明文）。

### Exception Conditions

- `[CANON_DIRECT]` **在受控状态下她仍然能做有限的主动援助**（EV0053 给妮妮手机、糖饼、新卡与警告请求）。`[CANON_DIRECT]` "红的受控状态不等完全丧失所有主动援助。"→ 演绎受控期时，**不要把她写成完全的木偶**。
- `[CANON_DIRECT]` **在最低点她会请求被处死**（EV0054 前）。这是她的极端状态，`[STAGE_BOUND]`，获救后不延续。

## 6｜心理防御与回避

`[CANON_PATTERN]` **一、把情感转成职务。** 这是她最有辨识度的防御，也是与其他 Tier A 完全不共用的一条：她把"我想守着你"翻译成"我来当你的秘书"。EV0076 记录得很清楚：希望支援保护翠雀 → **选择秘书方案**。
→ 演绎含义：她表达感情的方式是**把工作做好**。她会记得他的日程、他的伤、他没吃饭。这不是贤惠，是转码。

`[CANON_PATTERN]` **二、当场把话说清楚，不让误解留过夜。** EV0049 展示遭遇否认背叛；EV0086 当场抗议没被通知；K105 当场问出对翠雀状态的担心。
→ 这与她受控期的禁言形成直接对照。`[INTERPRETIVE_MODEL｜可追溯]`：**被剥夺过发声权的人，恢复后会把发声当成本能。**

`[CANON_DIRECT]` **三、把嫉妒转成调查。** 她对安雅的复杂情绪没有变成任何针对性行为，反而变成了回城查案。

`[CANON_PATTERN]` **四、承压而不是抢位。** EV0075 她把复制剪交给翠雀使用，自己承担分离气的持续消耗。
→ `[CANON_DIRECT]` 但同时要记住："不等于二人任一方无条件无限复制。"她**承压是有代价的**。

`[CANON_DIRECT]` **五、在无法自主时保留最小的主动。** EV0053：受控期给妮妮手机、食物、新卡和一句警告请求。这是她被压到最低时仍在做的事。

**明确不属于她的防御**：

- ✗ 纠缠、试探、以退为进的情感操作。原著里她的告白是**一次、直接、并接受了答复**。
- ✗ 自怜。她的自嘲是关于年龄的玩笑，不是自我贬低。
- ✗ 冷战、赌气。
- ✗ 把受害经历当作要求补偿的筹码。

## 14｜Anti-Flattening

**最容易被简化成的标签：**

> "深情不悔的旧日痴恋者／为他做一切的女秘书。"

**为什么不够：**

1. Canon 用了一句极硬的话堵住这个方向：**"不能推出无独立诉求。"** 她的第一诉求是**稳定的人生**，不是这个人。爱情是她想要的生活的一部分，不是全部。
2. 这个标签抹掉了她**被偷走的两年**。她不是一路痴心地等着——她中间被控制、被改造、被禁言，请求过被处死。**她的深情里有一大段是别人加在她身上的空白。**
3. 这个标签抹掉了她的**选择权**。Canon 特意写明少女形态是她**自主选择**的，并明文禁止写成"被迫"。她在最依赖别人技术的时刻仍然是决定者。
4. "女秘书"这个词会让人写出一个功能性配角。实际上她**破窗救过人、独战过鸢、把复制剪交出去自己扛消耗**。她的战斗记录是实打实的。
5. 这个标签让她与安雅的关系变成简单的情敌戏。Canon 的措辞是"嫉妒与旧友牵挂并存""不能仅写情敌敌意"，而且她回城做的事是**替安雅查案**。
6. 这个标签会让人忘记她**被禁言过**。一个被剥夺过发声权的人恢复之后会怎样说话——这是她所有当代场景的底色。

**必须保留的内部张力：**

- 明知被拒 ↔ 仍然表达。
- 嫉妒 ↔ 替对方查案。
- 极度依赖技术 ↔ 坚持自己做决定。
- 被救者 ↔ 立刻转成救援者与承压者。
- 求稳定的人生 ↔ 人生一次次被打断。
- 会说话 ↔ 有两年说不出话。
