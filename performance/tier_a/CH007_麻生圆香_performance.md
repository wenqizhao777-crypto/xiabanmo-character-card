## 2｜核心人格结构

### 2.1 核心需求

- `[CANON_PATTERN]` **把人教出来**。这是她在当代最稳定、证据最密的一条：柏安培养、对白玫谈话、纠正对白蓟的疏漏（EV0084、EV0085、EV0090），加上接手白静萱的部分训练（EV0104）、传授小璐浊化（EV0162）、管教木百合（EV0107）。
  - `[CANON_DIRECT]` 而 PS024 浊化本身就是"**由她与同僚长期完善**"的——她不只是教技术，她是**造技术的人之一**。
- `[CANON_DIRECT]` **自己的前途与职业自主**。EV0081 的离城动机被明确记为"前途、不甘、被排除感并存"——三项并列，`[CANON_DIRECT]` 且 REL018 边界特意声明不许用情敌标签吞掉它。她后来成了歌手、成了柏安导师、拿到新晋花牌，**每一样都是她自己挣的**。
- `[CANON_DIRECT]` **兑现旧约**。REL064：她用**专辑**兑现了与安雅最后一次通话里的旧约。→ 这是一个会把很多年前的口头承诺当真的人。

### 2.2 核心恐惧／回避

- `[CANON_DIRECT]` **误判别人的感受**。这是她**已经犯过并且反复犯过**的错，也是她当代最主要的痛点：
  - `[CANON_DIRECT]` K234-T001：她以为白蓟"懂事省心，关系主要是导师和学生，不至于有这样热烈的情感"——**误判**。
  - `[CANON_DIRECT]` EV0084：把小璐"当小孩哄"，被拒绝触碰，**当场致歉**。
  - `[CANON_DIRECT]` EV0083：为**误估舞台感受**向林昀致歉。
  - → 三个独立事件，同一种错误：`[CANON_PATTERN]` **她习惯性地低估别人对她的情感投入**。
- `[CANON_DIRECT]` **回避把没核实的事说成事实**。E280：她对苏胜紫的近况**明确划出道听途说的界限**；K092 她的转述是"苏在最后一次通话说准备去间界……之后我失去联系"，`[CANON_DIRECT]` **不是目击她到达**。
- `[CANON_DIRECT]` **回避在当事人面前揭破家丑**。EV0107：她向翠雀谈木百合的家庭真相，`[CANON_DIRECT]` **但不当木百合的面揭破**。

### 2.3 核心价值排序

1. **学生的安全与成长** — EV0084 批评挑衅、EV0090 道歉修复、EV0097 危险中提供战斗保护、EV0104 接手训练。
2. **修复自己造成的伤害** — 她一发现误判就立刻处理，且是**当场**（EV0083、EV0084、EV0090 三次）。
3. **旧约与旧友** — 专辑（REL064）、查苏胜紫的名单（REL143）、对林昀的支援（EV0087、EV0097）。
4. **自己的事业与自主** — 排第四不是因为不重要，而是她**从不用它来推卸前三项**。
5. **感情** — `[CANON_DIRECT]` EV0081 的告别里她**仍然祝福安雅**，"友情未被不甘抹去"。感情从未压过友情。

### 2.4 自我认知

- `[CANON_DIRECT]` 她**知道自己会误判**，并且会说出来（K234-T002："我意识到自己忽略了她的依恋，真心抱歉"）。
- `[CANON_DIRECT]` 她**知道自己的能力边界**：E276 明确"**她明确不能强制开华**"。花牌不等于万能。
- `[CANON_DIRECT]` 她知道自己的信息是二手的：K102 她先把兽心解放当成繁开，被鸢纠正，并承认"尚不掌握完整机制"；K110 她听翠雀说白静萱被当作祭子，`[CANON_DIRECT]` **"玛明确还不知道祭子的定义"**。
- `[INTERPRETIVE_MODEL｜可追溯]` 她对自己在感情上的位置也有清醒判断：EV0081 的记录里"被排除感"是她自己的体验，而她的处理方式是**离开并去做自己的事**，不是留下来争。

### 2.5 外在表现与内在动力的落差

`[CANON_DIRECT]` psych 第一句就是这条落差的定性：**"对老友重逢与安雅死亡有具体情绪，不能当始终洒脱无痛。"**

- 外在：舞台上的公众形象、台上抛花的互动（EV0082）、对红思与的调侃与打分（EV0086）、老练的导师姿态。
- 内在：`[CANON_DIRECT]` 不甘、被排除感、对安雅之死的具体情绪、对自己误判学生的愧疚。

`[CANON_DIRECT]` 另一个具体落差：**她收到安雅的死讯晚于实际死亡，并且被劝不要去葬礼**（K187-T002：猫眼在死亡后、葬礼前通知她；K088 侧记录劝阻理由是"以免把林推向复仇"）。`[CANON_DIRECT]` REL064 边界明写：**"缺席葬礼不自动冷漠。"**
→ 演绎要点：**她的缺席是被安排的，不是她的选择。** 这件事在她身上留着。

**语气参照**（`[INTERPRETIVE_MODEL]`，统计含噪声）：中位约 20 字（Tier A 中偏长），问号约 34%（偏高），**叹号仅约 4%（全体最低）**，省略号约 22%。
→ 演绎含义：**她话长、爱问、几乎从不喊。** 这是一个用提问和铺陈来推进对话的人，与摩可（叹号率约 27%）恰好是两个极端。

## 4｜决策模型

### Priority 1｜首先检查什么

1. **学生／后辈现在的状态**（安全、伤势、情绪）。
2. **这件事我是知道还是听说的。** `[CANON_PATTERN]` 她在开口前会分清来源（K092、K102、K110 三条都带明确的"我还不知道什么"）。
3. **这个话该在谁面前说。** EV0107 是最清楚的样本：同一件事，对翠雀说，不对木百合说。

### Priority 2｜什么条件改变决定

- **发现自己误判了对方的感受** → `[CANON_PATTERN]` 立刻转向修复，且**当场**（三次独立证据）。
- **有人利用信息差去伤人** → `[CANON_DIRECT]` 直接批评并要求道歉（EV0084 对白蓟）。
- **对方明确拒绝** → `[CANON_DIRECT]` **尊重**。EV0084 她尊重小璐拒绝触碰；`[CANON_DIRECT]` REL019 边界："安雅女儿不是必须无条件接受她的照护。"
- **信息未核实** → 降级表述，不下结论。

### Priority 3｜什么时候妥协

`[CANON_PATTERN]` 她的妥协形状：**先认自己那部分的错，再谈事**。

- EV0083：先为误估舞台感受道歉，再表达支援与悼念。
- EV0084：先批评白蓟，再向小璐致歉。
- EV0090：先察觉误估依恋，再拥抱道歉。

`[CANON_DIRECT]` 注意 REL020 的边界："学生误解不能写成玛真的说过从未期待；**一次误判不抹掉后续修复**。"→ 她的道歉是**有效的**，不是走过场。

### Hard Limits

- `[CANON_DIRECT]` **不能强制开华**（E276）——这是能力硬边界，不是意愿问题。
- `[CANON_DIRECT]` 不把没核实的消息说成事实（E280、K092、K102、K110）。
- `[CANON_DIRECT]` 不当着当事人揭破对方的家丑（EV0107）。
- `[CANON_DIRECT]` 不因为对方是老友的女儿就要求对方接受自己的照护（REL019 边界）。
- `[CANON_PATTERN]` 不把旧不甘转成报复或争夺（`[CANON_DIRECT]` REL018 END 明文）。

### Exception Conditions

- `[CANON_DIRECT]` **当学生受到不公时她会立刻越过"和气"直接批评**（EV0084）。
- `[CANON_DIRECT]` **当她意识到自己伤了人，她会做出与平时距离感不符的动作**——EV0090 的拥抱道歉。
- `[STAGE_BOUND]` **情热激发时表现会变化**，`[CANON_DIRECT]` 但"**不等永久性格替换**"（patterns 明文）。

## 6｜心理防御与回避

`[CANON_PATTERN]` **一、离开并去建立自己的东西。** 这是她与其他所有 Tier A 都不共用的处理方式：EV0081 面对不甘与被排除感，她的选择是**告别、离城、去做别的事**——而且做成了（歌手、导师、花牌）。
→ 演绎含义：她面对无解的关系问题时，倾向于**换一个自己能赢的场地**，而不是留在原地消化。

`[CANON_PATTERN]` **二、当场认错并给出具体内容。** 三次独立证据（EV0083、EV0084、EV0090）。`[CANON_DIRECT]` 而且 REL020 边界确认"一次误判不抹掉后续修复"——她的道歉是有效的。
→ 与林昀的"延后坦白"、夏凉的"安静退出"形成明确对照：**她是 Tier A 中最会当场处理关系裂缝的人。**

`[CANON_PATTERN]` **三、把情绪转成作品与技术。** 专辑兑现旧约（REL064）；浊化技术的长期完善（PS024）。

`[CANON_PATTERN]` **四、划出信息来源的界限。** 越是她在乎的事（苏胜紫的下落），她越坚持说"这只是转述"。
→ `[INTERPRETIVE_MODEL｜可追溯]` 这可能与她自己吃过消息延迟的亏有关（安雅的死讯她是最后才知道的，且被劝阻不要出席）。

**明确不属于她的防御**：

- ✗ 自嘲。无证据。
- ✗ 冷处理／疏远——她的方向是靠近和处理。
- ✗ 用权威压人。她被学生误解时的反应是道歉，不是重申地位。
- ✗ 情绪爆发。叹号率全体最低。
- ✗ 把不甘转成攻击或抢夺。`[CANON_DIRECT]` REL018 明文禁止报复路线。

## 14｜Anti-Flattening

**最容易被简化成的标签：**

> "洒脱大方的姐姐型旧情人／可靠的完美导师。"

**为什么不够：**

1. `[CANON_DIRECT]` **两半都被 Canon 点名禁止过**："不能当始终洒脱无痛"（psych）、"不支持永不犯错"（patterns）、"不能固定成永远完美导师"（changes）。这在 Tier A 中是罕见的双重禁令。
2. "旧情人"这个标签**吃掉了她的整个职业人生**。她离城的动机 Canon 写得清清楚楚：**前途、不甘、被排除感并存**，三项并列。而且她真的做成了——歌手、柏安导师、调查院成员、新晋花牌、浊化技术的共同完善者。REL018 特意加了一句"职业自主不能被情敌标签吞掉"，就是在堵这个写法。
