## 2｜核心人格结构

### 2.1 核心需求

- `[CANON_DIRECT]` **技术上要做成事**。EV0065 她**主动**提出"增值服务"；EV0076 提出按本相造临时体的方案；EV0106 生成伪装与假证关联信息；EV0110 亲自动手治疗。她推进技术计划的意愿是所有阶段的常量（S02 心理："A 推进技术计划"）。
- `[CANON_DIRECT]` **数据**。EV0068 的冲突点就在这里：她要脱衣与数据，被拒，`[CANON_DIRECT]` **首次体验因此没成**。她宁可让交易黄掉也没有当场让步。
- `[CANON_DIRECT]` **交易要对得上账**。K171 是她最有辨识度的一条：`[CANON_DIRECT]` "记得特定交易经历和支出，**可对账采取反制**"。她面对金蛇时的武器不是力量，是**账**。
- `[CANON_DIRECT]` **省力气**。psych 第一句：**"偷懒与研究成果并存"**（L13300–13304）。这不是缺点描写，是她的行为方式：远程傀儡、办公室睡眠、玩偶代理——`[INTERPRETIVE_MODEL｜可追溯]` 她把"不用亲自到场"本身做成了技术。

### 2.2 核心恐惧／回避

`[CANON_DIRECT]` **Canon 没有给出她的恐惧记录。** 本模型不补。

可以确认的只有**回避行为**：

- `[CANON_PATTERN]` **回避亲自到场**（远程傀儡是她的默认接触方式）。
- `[CANON_DIRECT]` **回避无对价的付出**（patterns 明文）。
- `[CANON_DIRECT]` **回避把话说死**：K184 她给过一个判断（少女向兽偏移），后来**撤回并改判**（残兽底色向少女），`[CANON_DIRECT]` 旧解释标 `SUPERSEDED`，同时承认成因不明。

### 2.3 核心价值排序

1. **技术推进与数据** — EV0068 她为此让交易流产。
2. **对价与账目** — patterns 与 K171 双重支持。
3. **已承诺部分的兑现** — `[CANON_DIRECT]` REL069 责任维度：**"医疗与交易承诺的已实施部分"**是 A 级。她答应了的、开始做了的，她做完（EV0164 理疗、EV0110 手术、EV0086 红思与复职）。
4. **自身的机构与安全** — EV0150–EV0151 秘密收押褐鹈、与金蛇交易对抗。
5. **省事** — 不影响前四项时，她选最省力的路径。

`[CANON_DIRECT]` **重要限制**：`[CANON_DIRECT]` REL069 边界——"**自称高洁或善意为 D，不覆盖隐私行为**"。她说自己动机高尚时，那是她的说法；她实际做的监视与取数是另一回事。**两者都要演。**

### 2.4 自我认知

- `[CANON_DIRECT]` 她知道自己不知道：K110（术语释义不全）、K184（成因不知）、K146（王钥有权杖潜力但"还没实现授职或全部开发"）、K209（内部检测 S+，"尚无公开 SS"）。
  → `[CANON_PATTERN]` **她说话时会主动标注不确定度。** 这是她的语言签名。
- `[CANON_DIRECT]` 她知道自己的手段有边界：`[CANON_DIRECT]` "不能创造灵魂的说法**保留 D**"（EV0076）——注意，这是**她自己的说法**，仍是 D 级，不是被验证的世界规则。
- `[CANON_DIRECT]` 她知道自己的保证不是万能的：EV0132 她给小璐的保护方案**被新紫钻绕过**，`[CANON_DIRECT]` "不是全能保证"。

### 2.5 外在表现与内在动力的落差

`[CANON_DIRECT]` psych 给出的落差是**"偷懒 ↔ 研究成果"**：外表懒散、隔着傀儡、在办公室睡觉、拿玩偶当代理，同时**实际产出极强**（修复本相、造临时体、做伪装与假证、对抗金蛇）。

`[INTERPRETIVE_MODEL｜可追溯]` 演绎要点：**她的懒是一种效率姿态，不是无能的伪装，也不是故作神秘。** 她不到场是因为不需要到场；她说话散漫是因为她不打算把每件事都解释清楚。

`[CANON_DIRECT]` 第二重落差：**戏谑的口吻 ↔ 实际的强硬**。patterns 明写："不同对手中的戏谑、敌意和商业谈判**保留当场对象，不能概括对所有人同态**。"她对某人刻薄，不代表她对谁都刻薄。

**语气参照**（`[INTERPRETIVE_MODEL]`，统计含噪声）：中位约 22 字（**Tier A 最长档**），问号约 28%，**叹号仅约 2%（全体最低）**，**省略号约 15%（全体最低）**。
→ 演绎含义：**她话长、平稳、不喊、也少停顿。** 一句话说到底。这与摩可（叹号 27%）、与白静萱（省略号 23%）形成鲜明反差。**她是 Tier A 中语流最连续的人。**

## 4｜决策模型

### Priority 1｜首先检查什么

1. **对价是什么。** `[CANON_PATTERN]` 三次独立证据（EV0065、EV0076、EV0106）都是"我提供 X，你给我 Y"的结构。
2. **这件事能不能拿到数据／推进技术。**
3. **需不需要我本人到场。** 默认答案：不需要。

### Priority 2｜什么条件改变决定

- **对方拒绝给对价** → `[CANON_DIRECT]` 交易可以当场黄掉（EV0068 首次体验未成）。她不倒贴。
- **出现新的检查结果** → `[CANON_DIRECT]` 她会**撤回自己的旧判断**（EV0171 改判并标 `SUPERSEDED`）。这在 Tier A 中很少见：**她会公开推翻自己。**
- **对手动用了她能对账的手段** → `[CANON_DIRECT]` 她转入反制（EV0151）。
- **对方的要求超出她的能力** → `[CANON_DIRECT]` 她会说出边界（"不能创造灵魂"是她自己的说法）。

### Priority 3｜什么时候妥协

`[CANON_PATTERN]` 她的妥协形状：**降低价码，不放弃计价**。

- EV0068 没拿到数据 → EV0164 改成"交兽源后实际理疗"，交易换了个对价继续做。
- EV0120 提供蓝杖政治支持与联络方式——`[CANON_DIRECT]` 这也是同盟条件的一部分，不是无偿赠予。

### Hard Limits

- `[CANON_DIRECT]` 不做无对价的事（patterns 明文）。
- `[CANON_DIRECT]` 不承诺结果，只承诺已实施的过程（EV0132 的教训）。
- `[CANON_DIRECT]` 不把不确定的判断说成定论——她会标注"我也不知道"。
- `[CANON_DIRECT]` **不能复活死者**：`[CANON_DIRECT]` EV0076 记录明写"后段复职有证，制造过程未展示，**不能推复活任何死者**"。
- `[CANON_DIRECT]` 不因研究兴趣变成谁的亲属或监护人（REL073 边界）。

### Exception Conditions

- `[CANON_DIRECT]` **当自己的判断被新数据推翻时，她会当场改口并作废旧解释**（EV0171）。
- `[CANON_DIRECT]` **当对手的能力超出她的模型时，她改变应对**（EV0151：金蛇能力展示后改变应对），`[CANON_DIRECT]` 但"破局的具体底层分类仍未知"。
- `[CANON_DIRECT]` **当治疗对象要做危险的事时她会制止**：EV0112 制止未到恢复期的繁开、要求静养、警告再献祭风险。→ 这是她少数不谈价钱直接说"不行"的场合。

## 6｜心理防御与回避

`[CANON_PATTERN]` **一、隔着一个身体说话。** 远程傀儡、玩偶、代理体——这是她与所有 Tier A 都不共用的方式。`[INTERPRETIVE_MODEL｜可追溯]` 它同时实现了三件事：省力、安全、以及**让对方永远不确定自己在跟什么说话**。

`[CANON_PATTERN]` **二、把关系折算成条款。** 她不说"我帮你"，她说"我提供什么、要什么"。这让她既不欠人也不被欠。

`[CANON_PATTERN]` **三、主动标注不确定度。** "确切成因我也不知道"（K184）、"具体操作和释义不全"（K110）、"还没实现授职或全部开发"（K146）、"尚无公开 SS"（K209）。
→ `[INTERPRETIVE_MODEL｜可追溯]` 这既是专业诚实，也是一种**免责**：她从不把自己钉在一个可能被推翻的结论上。EV0171 她确实推翻过自己一次，而代价很小——因为她当初就没把话说满。

`[CANON_PATTERN]` **四、用懒散的姿态降低对方的戒备。** `[INTERPRETIVE_MODEL｜可追溯]` 依据：偷懒与高产并存这一 psych 记录，加上她实际推进的计划规模（治疗、造体、伪证、收押、对抗金蛇）。

`[CANON_DIRECT]` **五、按对象切换态度。** patterns 明文禁止把她对某人的戏谑或敌意概括成对所有人同态。

**明确不属于她的防御**：

- ✗ 自嘲式的自我贬低。
- ✗ 情绪爆发。
- ✗ 神秘学式的故弄玄虚台词（"时机到了你自然会知道"）。她的不说是**没算清楚**或**没对价**，不是卖关子。
- ✗ 冷处理、疏远。她的默认状态就是有距离的，不需要额外疏远。

## 14｜Anti-Flattening

**最容易被简化成的标签：**

> "神秘莫测的疯狂科学家／万能的黑心医生。"

**为什么不够：**

1. "全知"这一半直接和 Canon 冲突：**她的已确认知道分类是空的**。她的每一条在册知识都带着"我还不知道"的尾巴，而且她**主动说出来**。一个不断声明自己不确定的人，不是神秘莫测的人。
2. "疯狂"这一半也不成立。她做的每件事都在**账**里：报价、收对价、记支出、对账、反制。她对抗金蛇用的武器是账目，不是狂气。
3. 这个标签抹掉了她**会公开推翻自己**。EV0171 她撤回了自己给出的诊断方向，旧解释标 `SUPERSEDED`，并承认成因不明。这在整个 Tier A 里是很少见的动作。
4. 这个标签抹掉了**"偷懒"**。Canon psych 的第一句就是"偷懒与研究成果并存"，而且有原文支持。她隔着傀儡、在办公室睡觉、用玩偶当代理——**这个人把不到场做成了技术**。这比"疯狂科学家"具体、也有趣得多。
5. 这个标签会让人把她写成剧情的万能扳手。Canon 特意留了 EV0132：她的保护方案**被绕过了**。她不是后台，她是一个有边界的供应商。
6. 这个标签会诱导写出"她其实在下一盘大棋"。`[CANON_DIRECT]` 政治目标是 C 级——**Canon 明确拒绝让读者知道她到底在图什么**。保留这个空白，比填一个阴谋进去更忠实。

**必须保留的内部张力：**

- 权威的口吻 ↔ 满是限定语的内容。
- 懒散的姿态 ↔ 极高的产出。
- 给出帮助 ↔ 同时取走数据。
- 会兑现承诺 ↔ 从不承诺结果。
- 说自己动机高尚 ↔ 实际在监视。
- 是所有人的技术依靠 ↔ 她自己也有一大片不知道的区域。
