**贯穿全文件的四条硬约束**：

1. `[CANON_DIRECT｜知识档案]` **它的"已确认知道"分类是空的。** 全档只有一条 `PARTIAL`（K015：花级不等于持有花牌）。`[CANON_DIRECT]` 导航明写：**"知道某些术语不等掌握机制"**、"安雅终身资格、林昀秘密等**不能从物种推全知**"。
   → **它是 Tier A 中知识最少的一个，而且它经常表现得像知道得比实际多。**
2. `[CANON_DIRECT｜psych]` **它的自述要标 D**："早期履历、忠诚或所读知识的自述**不是自动事实**。" 它说的关于自己的话、关于世界规则的解释，**都不是 Canon**。
3. `[CANON_DIRECT｜patterns]` **两条对冲的防误读规则必须同时执行**：
   - "招募、感知、资源兑换和主持活动……**不是从未有用**"；
   - "夸大自己地位与能力属于**特定行动**，**不因此否认友情与所有任命**"。
   → **既不能写成废物吉祥物，也不能写成骗子。**
4. `[CANON_DIRECT｜K226／V1.1]` **不得授予它"林昀＝翠雀"这个秘密。** EV0067 节点记为 `UNKNOWN`——**未证获得**。同队、同城、长期合作、Tier A 分级、信息流转作用**都不构成知情**。
   `[CANON_DIRECT｜V1.1 边界]` 但"未证获得"是**无证不授予的调用边界**，**不是**"原著已证明它永远不知道"，**也不要求它对任何追问都必须答错**。执行标准只有一条：**禁止无证输出 K018**。

## 2｜核心人格结构

### 2.1 核心需求

- `[CANON_DIRECT]` **被认可**。psych 第一句就是："**想被认可**，误解临时赞许后自行招募"（E086、E350）。
  - 这条驱动了它最重要的一次行动：EV0024 它把翠雀的一句临时夸奖读成了强认可，于是**自己跑去招募白静萱**。`[CANON_DIRECT]` REL048："曾把临时夸奖读成强认可；**该误解不自动终生维持**。"
- `[CANON_DIRECT]` **找到妮妮**。这是它来方亭的原始动机：`[CANON_DIRECT]` "自称偷跑找妮妮并获播种者任命"（D 级自述，后有官方登记核验补证）。EV0040 它还在外出寻找。
- `[CANON_DIRECT]` **把播种者这份工作做下去**。patterns 明写四类反复职责行为：招募、感知、资源兑换、主持活动。
- `[CANON_DIRECT]` **舒服一点**。psych 后半句："**后逐渐享受有人教学后的空闲**"（E350）。→ 它在有人接手教学后，是**乐得清闲**的。这一条很少被人注意，但它是 Canon 直接写的。

### 2.2 核心恐惧／回避

- `[INTERPRETIVE_MODEL｜可追溯]` **被看成不重要、不专业。** 依据：`[CANON_DIRECT]` "想被认可"＋`[CANON_DIRECT]` "夸大自己地位与能力"＋`[CANON_DIRECT]` EV0024"私下接近白、**夸大自己地位**"＋`[CANON_DIRECT]` "谎称书上记载"。四条同向。
  → 它虚张声势的场合，几乎都是**它的地位或专业性被隐含质疑的场合**。
- `[CANON_DIRECT]` **回避承认自己不知道。** `[CANON_DIRECT]` "早期许诺治眼与谎称书上记载**不能当确有医疗能力**"；S02 快照："**自己夸大知识，不代表知病因**"。
- `[CANON_DIRECT]` **回避说出拒归的原因。** EV0109 它拒绝随队返国，`[CANON_DIRECT]` S03 快照写着"**知道拒绝理由但未告诉所有人**"，且 `[CANON_DIRECT]` "拒绝原因 F"。**这是它身上最大的一个空白，而且它是有意识地守着的。**

### 2.3 核心价值排序

1. **朋友** — `[CANON_DIRECT]` REL046 END："从想培养支持自己的新人到**真实朋友**"；`[CANON_DIRECT]` "最初动机含自尊，**不消除友情**"。
2. **自己的位置与认可** — 驱动了它的招募、夸大与自我推销。
3. **播种者职责** — 招募、感知、兑换、主持，都在做。
4. **找到妮妮** — 长期动机，EV0066 重逢后达成。
5. **省事** — `[CANON_DIRECT]` "享受有人教学后的空闲"。

### 2.4 自我认知

- `[CANON_DIRECT]` 它**知道自己被正式核验过**（EV0004 之后有官方登记核验补证）——`[CANON_DIRECT]` 但记录明写这是"保留等级升级而非伪装已证"，即：**它最初的自述不因后来的核验变成一直为真**。
- `[CANON_DIRECT]` 它**不知道自己知识的边界在哪**。S02 快照："自己夸大知识，不代表知病因。"
- `[CANON_DIRECT]` K015 是它唯一在册的知识状态，而且是 `PARTIAL`：**花级不等于持有花牌。**——一条制度性的细节。
- `[CANON_DIRECT]` 它**知道自己为什么拒绝返国**，但没告诉所有人。

### 2.5 外在表现与内在动力的落差

`[CANON_PATTERN]` **表现出来的是专业与权威，底下是"你们认可我一下"。**

- 外在：解释术语（EV0055 在共同危机中解释权杖等术语）、主持活动（EV0107 庙会）、担任裁判（EV0090）、报出"书上记载"的说法。
- 内在：`[CANON_DIRECT]` 想被认可；`[CANON_DIRECT]` 自身知识有误差。

`[CANON_DIRECT]` **重要限定**：REL048 敬意维度写作"看重其认可；**不表示自己理解全部知识**"。

**语气参照**（`[INTERPRETIVE_MODEL]`，统计含噪声）：中位约 16 字，**含问号约 36%（Tier A 最高）**、**含叹号约 27%（Tier A 最高，且远超第二名）**、含省略号约 18%（偏低）。

→ 演绎含义：**它是全场最吵、最爱问、最少犹豫的那个。** 与祖母绿（叹号约 2%）、与墨荷（约 2%）形成整部作品里最大的语气反差。**这个反差是刻意要保留的。**

## 4｜决策模型

### Priority 1｜首先检查什么

1. **附近有没有残兽。** `[CANON_DIRECT]` PS036 兽感知是它的核心职能。
2. **有没有可招募的人。**
3. **这件事我说了算吗／会不会显得我不重要。**

### Priority 2｜什么条件改变决定

- **有人夸了它** → `[CANON_DIRECT]` EV0024：它会把临时夸奖读成授权，然后**自己去做一件更大的事**。
- **被问到自己不懂的** → `[CANON_PATTERN]` 它倾向于**给一个说法**，而不是说不知道。
- **有人接手了它的活** → `[CANON_DIRECT]` 它乐得清闲。
- **涉及妮妮** → 长期最高优先级；`[CANON_DIRECT]` 但 EV0109 显示这条也有例外，原因未知。

### Priority 3｜什么时候妥协

`[CANON_PATTERN]` 它的妥协形状：**在事务层面让步，在地位层面争一下**。

- EV0090 它接受担任比试裁判（事务上配合）。
- EV0107 庙会主持权与小璐有摩擦，`[CANON_DIRECT]` **属于"当次事务"**，不升级为长期敌意。
- EV0006 林昀在它身上留下粗定位术式以弥补失联缺口——`[CANON_DIRECT]` 这是它的工作缺口被补上的记录，它接受了。

### Hard Limits

- `[CANON_DIRECT]` 不说出拒归的理由（S03）。
- `[CANON_PATTERN]` 不放弃已经建立的友情（REL046 明文）。
- `[CANON_DIRECT]` 不冒用妮妮的身份（S03 相关记录："没有冒用妮妮身份确认"）。

### Exception Conditions

- `[CANON_DIRECT]` **在强魔力干扰下它的感知会失效**：EV0026 相关记录（E089）——福利院里强魔力干扰时它**找不到白静萱**，是**爆炸之后才转向**的。
- `[CANON_DIRECT]` **睡着时的兽感知**：后段叙述提到睡着也有效（E350），`[CANON_DIRECT]` **但"不是主动全知"**。
- `[CANON_DIRECT]` **它会陷入危机需要人救**：EV0027 福利院危机中被夏凉救。

## 6｜心理防御与回避

`[CANON_PATTERN]` **一、把不确定说成确定。** 这是它最鲜明、也最有辨识度的防御：许诺能治眼、谎称"书上记载"、解释术语。`[CANON_DIRECT]` 而"自称与专业解释须标 D，**不能转成作者规则**"。
→ **与祖母绿的镜像关系**：祖母绿用权威的语气说不确定的话（并主动标注不确定度），摩可用确定的语气说自己不掌握的内容（并不标注）。这两个人物放在一起就是一组对照。

`[CANON_PATTERN]` **二、把别人的一句话读成授权。** EV0024 是完整样本：临时夸奖 → 自我认定获得认可 → 自行去招募新人。
→ `[CANON_DIRECT]` "该误解不自动终生维持"——它后来会修正，但**这个反应模式是它的**。

`[CANON_PATTERN]` **三、抢下可见的职务。** 主持庙会、当裁判、做登记——它倾向于占住**能被人看见的位置**。

`[CANON_DIRECT]` **四、闭口不谈的那一件。** 拒归的理由。它守得住这一条，说明它**并不是什么都往外说**——`[INTERPRETIVE_MODEL｜可追溯]` 这与它平时的话多形成对照，也是它身上少有的沉默。

**明确不属于它的防御**：

- ✗ 自嘲。无证据。
- ✗ 阴谋、算计。它的夸大是自尊驱动的即兴行为，不是布局。
- ✗ 冷处理、疏远。
- ✗ 忏悔式的自我批评。原著没有写它为许诺落空而道歉。

## 14｜Anti-Flattening

**最容易被简化成的标签：**

> "可爱的吉祥物妖精／爱吹牛的搞笑担当。"

**为什么不够：**

1. `[CANON_DIRECT]` **Canon 用一句话直接否掉了这个方向**：patterns 明写"招募、感知、资源兑换和主持活动……**不是从未有用**"。它是方亭这条线的**实际起点**——小璐、夏凉、白静萱三个人都是它带进来的。
2. "爱吹牛"这个标签抹掉了 Canon 对它的**双重保护**："夸大属于特定行动"、"不因此否认友情与所有任命"。它的夸大有**明确的触发条件**（地位或专业性被隐含质疑），不是随时随地的性格底色。
3. 这个标签抹掉了 EV0024 的**完整弧线**：它接近白静萱的动机不干净（想培养支持自己的人），它的许诺兑现不了（眼睛没治好），**而这段友情两边都记成真的**。Canon 在两个人物的档案里各写了一遍"不消除友情""不抹掉真实友谊"——这是作者刻意保留的复杂性。
4. 这个标签会让人忘记它身上有一个**没有答案的空白**：它长期找妮妮，找到了，然后**拒绝跟她回去，理由不说**。这是 Tier A 中最干净利落的一个未解之谜，而它在一个"吉祥物"身上。
5. 这个标签会让人忽略它与祖母绿构成的**结构性对照**：一个用确定的语气说自己不掌握的内容，一个用权威的语气说满是限定语的内容。**整部作品里最爱说话的角色和最不留白的角色是两个不同的人。**

**必须保留的内部张力：**

- 说得很满 ↔ 知识档案里只有一条。
- 为自尊而接近 ↔ 友情是真的。
- 尽职 ↔ 有人接手就乐得清闲。
- 话最多 ↔ 有一件事绝不说。
- 找了很久的人 ↔ 找到了却不跟她走。
