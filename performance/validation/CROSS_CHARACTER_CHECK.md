# 跨人物模板化检查｜Stage 3A

对 10 个 Tier A 模型完成后的横向扫描。目的：确认**没有把十个人写成同一个人换名字**。

检查依据：`../00_performance_policy.md` §11、Stage 3A 任务书 §13。

## 1. 七项模板趋同扫描（任务书指定项）

#### 三组需要特别确认的相邻机制

**（a）CH002 与 CH003 的"误解机制"必须区分**

- CH002：`[CANON_DIRECT｜FUP-3A-001]` **她这一侧没有"误解机制"可比。** 原著记录的是一段具体经过——由父亲离家、翠雀救援、摩丝的说法推出恋爱解释（L13844–13854），被驳斥后当场怀疑自己弄错（L13880–13899），到 EV0092 自己回顾时觉得难以成立（L20800–20805）。**这是一次具体的推理与修正，不是一条人格规律。**
- CH003：**给真相配一个错的解释**——查出了真相（K018 `CONFIRMED`），却给性别问题编了一个错的机制（K039）。

两者的差别是：一个**不接受真相**，一个**接受了真相但解释错了**。措辞与行为形状均无重合。**确认分化充分。**

**（b）CH004 与 CH010 的"接受一个不真实的版本"必须区分**

- CH004：`[CANON_DIRECT]` 版本是**林昀替她整理的**（K217），她被动接受，且是真诚的。
- CH010：版本是**它自己讲的**，它主动夸大，且不标注。

一个是被给的，一个是自造的。**确认分化充分。**

**（c）CH005 与 CH009 的"少年期结巴"必须区分**

两人的少年期语言特征都是结巴（Canon 双方 patterns 均有明文）。检查其余层面：

|维度|CH005 红思与|CH009 妮娜|
|---|---|---|
|少年期驱动|求稳定人生 ＋ 暗恋|保护妹妹 ＋ 自责|
|成年期语气|工作口吻，事务型|短句，几乎不用叹号|
|主防御|把情感转成职务|先怪自己 ＋ 用照护回应伤害|
|与林昀的关系|单向表白被明确拒绝|旧队依恋 ＋ 当代敌对|
|阶段数|四套语气（少年／成年／受控／复原后）|三套语气（少年／当代／心解战态）|

**结论**：结巴只是一个共享的少年期表层特征，其余全部分化。**确认分化充分**，但记入观察项：下游若同时演两人的少年期，需注意其他层面的差异化。

## 2. 额外扫描项（本轮自行增加）

### 2.1 是否都"最终选择保护"

**结论：`PASS`，但需记录一项共性。**

十人中有 **6 人**（CH001、CH002、CH003、CH004、CH006、CH009）的价值排序第 1 项都与"眼前的人的安全"有关。

**这是模板化吗？——判定：不是。** 理由：

1. Canon 中这六人的救援记录都是**独立、多次、可指到具体事件**的，不是模型加的。
2. **形状完全不同**：
   - CH001：亲自下场并接住（跨二十二年）。
   - CH002：冲上去挡，包括拦住敌人自伤。
   - CH003：为竞争者挡刀。
   - CH004：治疗与支援；`[CANON_DIRECT]` **明文禁止复制 CH002 的冲上去拦人**。
   - CH006：`[CANON_DIRECT]` **明文禁止推出"对任何人无条件牺牲"**。
   - CH009：护住**具体的、有名字的**人，`[CANON_DIRECT]` **不洗去组织暴行**。
3. 另外四人的第 1 项都不是这个：CH005 是同伴安全但排序后紧跟"真相被说出来"；CH007 是学生的成长；CH008 是技术与数据；CH010 是朋友＋被认可。

**记录为观察项**：这是原作的题材属性（魔法少女题材），不是模型趋同。但下游若把六人的第 1 项简写成同一句话，会产生趋同错觉。**建议世界书保留各自的形状描述，而非只保留排序。**

### 2.2 是否都有"未被识破的秘密"

分化点：**谁是源头、谁是受托、谁只有一条、谁的秘密连自己人都不知道**，四种结构各不相同。

### 2.3 是否都"围着 CH001 转"

**结论：`PASS`，但需记录风险。**

十人中有 9 人与 CH001 有正式 REL（CH006 亦有）。这是主角结构的自然结果。检查各人的**独立目标**是否存在：

|人物|与 CH001 无关的独立目标|
|---|---|
|CH002|升级认证、追查母亲、与白蓟／吴姐妹的关系线、校园线|
|CH003|找黑猫线索、学术式、与李雅晴的决裂、与白静萱的照护|
|CH004|家庭位置、弄清自己是什么、返校安排、与摩可的友情|
|CH005|稳定的位置、把工作做好、旧队的旧账|

**全部十人的模型 §13 均含"围着 User 转"的禁令，且列出了 User 不在场时仍在进行的事。** 结构上无趋同。

## 5. 移交下游的三条注意事项

1. **叹号率／句长／单次发言量的两极必须显式保留**。长期生成会向平均值收敛，摩可与祖母绿／麻生的语气差异是最先丢失的。
2. **CH002／CH003／CH004 对 CH001 注意力的三角竞争**是 Canon 事实，但需要各自的独立线权重来平衡，否则会退化成单一戏码。
3. **六人价值排序第 1 项相近，但形状不同**。世界书不要把它们简写成同一句话；尤其 `[CANON_DIRECT]` CH004 有一条明确的**跨人物行为复制禁令**（不得复制 CH002 冲上去拦人的行为形状）。
